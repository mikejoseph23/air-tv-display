# Air TV Display

macOS AirPlay screen-mirroring receiver (AppKit, Swift) wrapping UxPlay's protocol library (`thirdparty/UxPlay/lib`, git submodule). Plan and history: `airplay-receiver-plan.md`.

## Build

```bash
git submodule update --init
scripts/setup-deps.sh        # once per machine: universal OpenSSL + libplist under ~/.cache/airtv-deps/universal
xcodegen                     # after editing project.yml (the generated project is checked in)
xcodebuild -project AirTVDisplay.xcodeproj -scheme AirTVDisplay -derivedDataPath build build
xcodebuild test -project AirTVDisplay.xcodeproj -scheme AirTVDisplayTests -derivedDataPath build
```

- `AIRTV_DEPS_PREFIX` (in `project.yml`) points at the dependency prefix; override it on the `xcodebuild` command line.
- The test target is unhosted and compiles app sources directly; add a source to its `sources:` only if a test needs it.
- `AirTVDisplay/Info.plist` is hand-edited (not generated by xcodegen) and is the single source of truth for the version and Sparkle's `SU*` keys.

## Release

Releases are built and signed on the **Mac Studio** (`ssh michaeljosephwork@Mac-Studio.local`), which has the Developer ID certificate, the notary profile and the Sparkle EdDSA key. Run these from a logged-in Terminal there, not over SSH: the login keychain is locked in an SSH session, so notarytool and sign_update can't read it.

One-time setup on the Studio: clone the repo with submodules and run `scripts/setup-deps.sh` (no Homebrew or sudo; verified there 2026-10-31). xcodegen is already in `/usr/local/bin`.

1. Bump **both** `CFBundleShortVersionString` and `CFBundleVersion` in `AirTVDisplay/Info.plist` (Sparkle compares `CFBundleVersion`).
2. Write the release notes in the `<description>` of `deploy/updates/appcast.xml`.
3. Build, sign, notarize, staple:

   ```bash
   SIGN_ID="Developer ID Application: INTERAPP DEVELOPMENT, INC. (UU626VCLYW)" \
   NOTARIZE_PROFILE="mrm-notary" scripts/make-dmg.sh
   ```

   `mrm-notary` is the profile mac-resource-monitor uses; any `notarytool store-credentials` profile for team UU626VCLYW works.
4. `scripts/stage-release.sh` EdDSA-signs the DMG, rewrites the appcast and stages `dist/upload/` (versioned DMG, `appcast.xml`, `web.config`).
5. `deploy/pack-for-lymedeploy.sh` packs and pushes `AirTVDisplay.Downloads <version>`, then create and deploy a release of project `air-tv-display-downloads` (defined in `deploy/deploy.yaml`). It publishes to `https://iadev.net/air-tv-display/` and purges Cloudflare's cache for the appcast.
6. Commit the rewritten `deploy/updates/appcast.xml` and the version bump.

Without `SIGN_ID`, `make-dmg.sh` makes an ad-hoc signed DMG for local testing; `stage-release.sh` refuses it unless `ALLOW_UNSIGNED=1`.

Details:

- **Feed:** `https://iadev.net/air-tv-display/appcast.xml`. DMG: `AirTVDisplay-v<version>.dmg` in the same folder.
- **EdDSA key:** `SUPublicEDKey` in `Info.plist` is the public half, shared by all of Mike's apps. The private key is in the Studio's login Keychain (service `https://sparkle-project.org`, account `ed25519`). Never in the repo.
- **Universal:** Release builds `arm64 x86_64`; `make-dmg.sh` fails if the app binary or `libcrypto.3.dylib` is missing a slice.
- **Hardened runtime entitlements** (`AirTVDisplay/AirTVDisplay.entitlements`): no sandbox, no exceptions. libcrypto and Sparkle are signed with the same Developer ID, so library validation passes; audio output and listening sockets need no entitlement. The two `network` keys only matter if the sandbox is ever enabled.
- **License:** the app is GPLv3 (it links GPLv3 UxPlay/playfair); our own files carry MIT SPDX headers. See `thirdparty/LICENSES.md`. `LICENSE` and `LICENSES.md` ship in the bundle's Resources.
